# Asset Notes

The active UI assets for this project are lightweight and live inside the app itself.

## Current Assets

- `src/assets/hero.png`: primary illustration used by the prep hub interface.
- `src/assets/react.svg`
- `src/assets/vite.svg`
- `public/favicon.svg`
- `public/icons.svg`

## Styling Direction

The interface uses:

- dark glassmorphism panels
- cyan / indigo / pink accent gradients
- `Outfit` for headings
- `Inter` for body text
- `JetBrains Mono` for code and data views

## Data Assets

The largest project assets are generated study datasets:

- `src/data/dsaSolutions.json`
- `src/data/dsaTheories.json`
- `src/data/dsaTraces.json`
- `src/data/sqlSolutions.json`
- `src/data/sqlTheories.json`

These are application content assets rather than design mockups.
